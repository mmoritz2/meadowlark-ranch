# Riding fairness and herd guidance — 2026-10-12

The research in `docs/star-equestrian-evidence-2026-10-05.md` points to readable riding challenges followed by a visible horse/reward handoff. This change removes two concrete interruptions in that loop: jump timing sampled after crossing a log, and a pressure marker with no navigable rider approach.

## Behavior

Native/reference jumps now interpolate the native animation age at the rail plane between eligible consecutive frames. The existing Perfect/Good boundaries are unchanged. Resets, refusals, course/rig changes, invalid clocks and large discontinuities reject interpolation and retain the existing fallback. This is continuous-frame timing, not new teleport or swept-rail-span validation. The last credited fence records frame age, rail age, grade and whether interpolation was used.

Solo roundup rings now guide the rider along validated waypoints around scenery and the horse’s six-metre avoidance zone before reaching a pressure position. The HUD distinguishes approaching from guiding. Detour routes retain a cursor instead of rerunning a grid search for every small movement; the current leg is revalidated against live geometry on every read. Direct pressure targets refresh after 180 ms, while an unchanged blocked solve retries after 250 ms. Fence-edge approaches can use a wider angle while retaining true guiding alignment. If guiding positions are unreachable, a separate marked recovery position is offered only when the existing horse escape helper predicts a clear homeward turn, using the actual remembered bypass side and .7 m footprint. This phase never claims good guiding pressure; it refreshes to seek normal guiding again. Searches are bounded and fail closed. The full-herd hint asks for a steady trot; beginner guidance retains a walk. Horse motion, timers, scoring, clearance and payouts are unchanged by the routing work. Shared sessions retain their existing guidance behavior.

Story and Rider Journey expose separate next-objective tracks, and race favoured-trait matches use effective-stat thresholds rather than personality/genetic preparation choices. A substantive next step is a two-rider Cottonwood post relay with an explicit visible parcel handoff, extending its existing solo world activity. It needs independent real clients, actual riding/handoff, absence/disconnect/pause and reordered-message checks, and durable completion/reload evidence before it can be called working.
