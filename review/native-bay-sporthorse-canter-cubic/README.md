# Bay Sporthorse Canter: periodic cubic interpolation pilot

This private candidate repairs the **velocity discontinuities at the original linear key joins** without changing the solved Canter key poses. [cubicize.py](cubicize.py) requires the original left/right Canter's independently solved, uncopied loop recurrence (maximum 0.00001088° left, 0.00000131° right), then appends periodic centered Hermite tangents to each of the 82 rotation/translation tracks per lead. It projects quaternion tangents onto each key quaternion's tangent space. The original 129 keyed values on every track remain **bit-exact**, including the independently solved final pose. The first and last tangent rows match exactly. The original binary prefix, all five meshes, 677-joint skin, weights, binds, materials, and tack remain unchanged. The [repacked model](model.glb) SHA-256 is `0162dd10be27992ae53c18772ad49eb29e2dffcb434b4521a7c849e3642429fe`; the [cubic summary](cubic-summary.json) pins its source and verifies preservation.

The [interpolation audit](interpolation-report.json) evaluates normalized glTF cubic quaternion motion at 64 substeps per 5 ms source segment across **all** keyed joints. Peak local angular rates are 995°/s (left) and 969°/s (right), versus 956°/s and 955°/s for the original linear interpolation. Maximum between-key orientation change from that original is 0.217° / 0.261°. Pre-normalization cubic quaternion norms stay within 0.999980–1.000010. Pelvis translation changes by at most 0.000538 **source rig units** between keys; its source local translation is not directly in game meters. The analytic tangents make joins C1, but these high peak rates remain a visible naturalism concern.

The [browser scan](browser-summary.json) uses actual Three.js glTF playback and real skinned body vertices for **512 phases per lead**. Both leads have 677 finite bones, 61 sampled all-feet-off flight phases, body minimum at least 0.797 mm over the fixed floor, planted whole-hoof minima in 0.797–4.024 mm, and no page errors. The phase seam changes sampled hoof centroids by at most 0.11 μm. [Left side](left-side.png) and [right quarter](right-quarter.png) are representative poses. `qa.cjs` and `audit-interpolation.py` reproduce these checks against a local project server; full phase rows go to ignored `output/native-bay-sporthorse-canter-cubic/`.

This is a bounded **interpolation correction**, not a new anatomical solve or mounted transition approval. The original Gallop is still unsupported. No production assets, breed registration, or deployed files were changed.
