# Front-hoof tuck and late Trot recovery

White Western, Bay Western and Bay Sporthorse retain their full native rig, realistic coat, Western tack and creator credits. Front hooves tuck farther backward while lifted. During Trot, the front cannon opens forward into the hanging-hoof pose sooner, making that pose easier to read at normal speed. The back legs and planted source poses are preserved.

Each model uses its own immutable original head kit. A monotone late-swing phase map advances only the ten fore rotation tracks of Target Native Trot by up to .05 of one cycle. Its quintic lobe spans swing u .55–.98, peaks at .75 and returns to the original landing. Clip duration, gait clocks, stride, travel, peak knee flex, body/head/seat/hind curves and bind/static data stay unchanged. The White source uses LINEAR interpolation; the Bay and Sporthorse source curves use their own normalized Hermite evaluation with time-map chain rule tangents, retaining all unchanged key rows. The phase map has a positive minimum derivative around .272. This is visual authoring from the supplied photo, not a measured physiological gait model.

The four distal fore rotation channels per gait then add a 30° fetlock and 12° coffin-like fold during Walk, Trot and both Canter leads. Exact original distal companion clips stay on the sole source mixer. Authored fold samples the same action times and fades with source whole-hoof clearance over 12–42 mm. A narrower 12–35 mm fade caused two fallback events in White's Trot→Walk phase .75 test; the wider continuous fade removed both events. The retained fallback protects poses outside the audited envelope. No root lift, joint translation or floor projection is added.

The supplied Arabian image shows late forward recovery, with the cannon nearly vertical and hoof hanging. In the White phase-only test, the left raised near-vertical pose lasted about 39→68 ms. Swing clearance decreased by up to 39 mm, while actual whole-hoof ground penetration and planted poses stayed unchanged. The right source rest pose is asymmetric, so this is not an exact bilateral photographic reconstruction. No stock photo is distributed with the kit.

Original source faults remain, including small Trot penetration and deeper faults in some source crossfades. Verification measures *added* penetration rather than claiming the source never crosses ground. Preserved LINEAR curves are not total C1; Walk recovery remains brisk. No Gallop/Jump clips are added, the 80 legacy breed rigs are not replaced, and both existing native dragons remain unchanged.

`transition-qa.json` tests 390 paired original/candidate cases at 30 and 60 fps, 7,410 frames, all 677 joints, body/head/seat and both full hind chains, actual whole-hoof vertices, action phases and fallback counts. `mounted-qa.json` tests the actual Ranch rigs across all 12 horse/gait combinations, rider boots/stirrups, reins, input and lifecycle, plus exact loaded runtime pins. Model subfolders contain the portable two-stage builders and independent preservation, curve and gated geometry audits. `live-mounted-qa.json` records the exact deployed game only after its final build is verified.
