# Private Bay Sporthorse Walk pilot

This is a **Walk-only, review-only** animation for the [prepared Bay Sporthorse](../native-breed-targets/README.md). It is not registered in the game and has no mounted rider or faster-gait approval. The WildMesh 3D source remains [CC BY-NC 4.0](../../assets/models/horse-imports/wildmesh-white-western/provenance.json); no model was downloaded for this pilot.

The [model](model.glb) has SHA-256 `512697ed36c8edb92cb31555e672026bb552d1f97d366d9afe9ac88b92e2dbf5`. Its immutable [rest input](../native-breed-targets/bay-sporthorse/rest.glb) has SHA-256 `8f7f83e9669dc063dcb38455f8658369774ec0ce9b9eb81c2e7742e7d013d6a8`. The builder derives the four hoof masks, native leg pivots, skinned sole points, floor, and body height ratio **0.9119853** from that target. It does not copy another horse's joint rotations. The resulting 1.12-second four-beat Walk uses 65% stance, a 0.18240 m half-stroke, 0.04104 m smooth swing lift, and nominal **0.50109 m/s** travel. The original 677-joint target, five meshes, skin weights, inverse binds, materials, maps, groom, tack, and source binary prefix are preserved; one 82-channel `Target Native Walk Rollover` clip is appended.

The [build summary](build-summary.json), [actual float32 joint audit](step-audit.json), [256-phase browser QA](qa-summary.json), and [preservation audit](preservation.json) are saved here. All 677 browser poses were finite with no page errors. Exactly two or three hooves were scheduled to support every sampled phase. Planted whole-hoof minima were **0.715–1.363 mm** above the fixed floor; no body penetration appeared. At nominal travel, the maximum regional heel/sole/toe fore/aft drift was **0.123 mm**. The independently solved loop closure is **0.0000122°**, and the largest actual keyed limb step is **4.938° in 8.75 ms**. Side and quarter [stance](side-stance.png) / [swing](quarter-swing.png) stills show an upright torso and intact Western tack. The [viewer](review.html) has 1× playback.

This remains a pilot. The offline swing-height target misses by up to **5.20 mm**, so its broad `authoredGridPass` is false even though stance and browser contact checks pass. The foreleg correction touches an angle cap in 18 left and 17 right samples of the 128-frame authored cycle; the 564°/s peak joint rate is brisk. The solver holds lateral torso roll at zero to keep stance hooves planted; this limits natural sway. The sampled poses and contact measurements do not certify natural full-speed cadence, breed-specific movement, rider contact, turns, or transitions. Those need separate review before integration.

Reproduce from the repository root with `python3 review/native-bay-sporthorse-walk/build.py`, run `python3 review/native-bay-sporthorse-walk/summarize.py --stage`, then run the local [joint](audit-steps.py) and [preservation](audit-preservation.py) audits, then serve the repository over HTTP and run `QA_PORT=<port> node review/native-bay-sporthorse-walk/qa.cjs`. Finally, `python3 review/native-bay-sporthorse-walk/summarize.py` pins the model and compact summary. The full frame-by-frame solver trace stays in ignored `output/native-bay-sporthorse-walk/`.
