# Measured native gait controller

This private runtime extension plays the saved white horse's refined Walk, Trot and both Canter leads on the original full rig. It reads their measured clip names, durations, stroke, stance duty and speeds from [the kit record](../native-horse-kit/preservation.json). The earlier [Walk-only prototype](../native-horse-controller/README.md) remains frozen.

Place the untouched native scene inside a separate actor group, then call `createNativeHorseController({THREE, mixerRoot: scene, clips, actor, gaits: kit.gaits})`. Set `walk`, `trot`, `canterLeft`, `canterRight`, `stand` or `rest`, and call `update(dt)`. Keep normalization translations inside the actor and apply uniform display scaling to the actor or its ancestors. Preserve the inner native scene's original scale and forward axis (+Z); arbitrarily scaling or rotating it separately is unsupported.

The controller verifies each gait clip's duration and the identity `speed = stroke / (stanceFraction × cycleDuration)`. It advances the outer actor along its forward axis at that gait's measured speed, accounting for the actor and inherited world scale. It restores every bone's original position, rotation and scale before changing clips, so a Walk-only groom or body channel cannot contaminate Idle or another gait. Missing clips, inconsistent timing records, unknown gaits, invalid deltas and updates after disposal are rejected.

The [browser check](qa-summary.json) compares all 677 bone poses to direct playback of each saved clip across two loops with irregular frame times, checks traveled distance, restores Idle/rest after each gait, and checks rotated/scaled world travel. It also verifies missing-clip, metadata, unsupported-gait and disposal behavior. Run with a local server: `NODE_PATH=$(npm root -g) QA_PORT=<port> node review/native-gait-controller/qa.cjs`. Reports write to ignored `output/native-gait-controller/`.

This is integration preparation, without a production roster change. Mode switches are instantaneous and gait-specific riding, steering, transitions, gallop and jumping remain unfinished. The controller does not infer that an animation is natural from the existence of a clip. Horse source and derivative credits remain [WildMesh 3D, CC BY-NC 4.0](https://sketchfab.com/3d-models/horse-realistic-3d-model-demo-free-65d6a70a6721495f938c93e80a5998e4).
