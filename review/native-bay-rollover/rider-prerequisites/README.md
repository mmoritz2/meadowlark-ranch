# Bay rider and tack: static prerequisite

This folder preserves a **rest-pose measurement**, not an approved mounted Bay or gait. The two screenshots show the original static Bay cage fit (`output/native-bay-preparation/native-bay-rest.glb`, SHA-256 `6110fb3bcfe6ba6660c9c05d67269bc800d19706fab54db29633003d87f0a6a3`) with the existing 65-bone rider. They were **not** captured from the tracked [Bay rollover model](../model.glb) (SHA-256 `8f622bf3b22244ba1b6a39c72e3cb1ce6f2e378bb7eb731a22caba33b2459814`). The rollover [preservation checks](../preservation-checks.json) say its original rest scene and binary prefix are unchanged; mounted animation and reins still need their own review.

The native rig and tack topology are reusable: all 677 joint IDs/order, five meshes' indices/joint indices/weights, and the 300 connected Western-tack components match the white source. Bit-ring pieces **209/205**, stirrup-tread pieces **91/89**, outer-neck rein guides **72/141**, and the original rein pieces retain their IDs. Bay skinned positions and binds differ, so the measured white coordinates cannot be copied. [Actual coordinates](actual-coordinates.json) records the Bay game-space seat, tread, bit-ring, rein-grip, and sampled neck-guide positions in metres (+Y up, +Z forward, floor Y=0).

The Bay seat is at `(0, 1.478879, 0)`. The tread centers are `(-0.369247, 0.885693, 0.182624)` and `(0.354162, 0.887347, 0.168727)`. In this one static pose, the existing rider's leg IK places both skinned boot soles within 0.004 mm of those treads; knee angles are 117.0°/114.4° and the leg chains have 0.208/0.218 m reach margin. The original source rein-grip vertices remain **0.230/0.219 m** from the rider's relaxed hands. The screenshots are [side](bay-rider-side.png) and [quarter](bay-rider-quarter.png). These measurements establish static leg reach only; they do not establish moving seat stability, rein contact, or gait quality.

[analyze.py](analyze.py) reproduces the topology/anchor calculations and writes a full-precision report to ignored `output/native-bay-rider-plan/`. It requires the original static Bay rest file. If that ignored file is absent, regenerate the full-joint Bay source with [the tracked Bay proof](../../bay-native-proof/build-fulljoint.py), then run [the tracked static preparation](../../native-bay-walk/prepare.py). The rider source anchors are [here](../../native-rider-reins/anchors.json). This WildMesh derivative retains its **CC BY-NC 4.0** attribution and restriction, recorded in the [source provenance](../../../assets/models/horse-imports/wildmesh-white-western/provenance.json).

After Bay Walk passes a separate motion audit, a mounted candidate should calculate these Bay contacts on each frame, adapt the display reins to Bay bit rings/neck guides/relaxed hands, and check saddle, boot, and rein contact throughout the cycle. No static viewer or browser QA runner is included in this tracked folder; the original private fit run remains under ignored `output/native-bay-rider-plan/` on this worktree.
