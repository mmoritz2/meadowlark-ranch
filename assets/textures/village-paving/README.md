# Cottonwood paving

[Patterned Cobblestone](https://polyhaven.com/a/patterned_cobblestone) by Rob Tuytel / Poly Haven, [CC0](https://polyhaven.com/license).

Imported from the official Poly Haven API. Source JPEG MD5 checksums were verified before converting to local WebP files. The manifest records source URLs, authors, original and output checksums, sizes, colour spaces, and the photographed 2.5 metre patch. Diffuse and OpenGL normal maps are 1024px; packed AO/roughness/metalness is 512px. No third-party executable is required. The game uses the diffuse, normal, roughness and occlusion channels.

All layout, paving geometry, fountain and planting arrangements are original Meadowlark Ranch work. Star Equestrian screenshots were used for visual reference only and are not distributed with the game.
