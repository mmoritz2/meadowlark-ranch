# Native horse and dragon assets

Four separately selectable native models are being integrated into Meadowlark Ranch: White Western, Bay Western, Black Dragon and European Dragon. The realistic white horse and fitted Bay preserve their full original 677-joint skins and Western tack. The Black Dragon preserves its 232-joint creator rig; European Dragon preserves its 169-joint rig.

| Model | Current motion | Record |
| --- | --- | --- |
| White Western | Creator Idle, rebuilt Walk, diagonal Trot, both Canter leads | [Native kit](../../../review/native-horse-kit/README.md) |
| Bay Western | Default standing pose and rebuilt Walk | [Bay Walk](../../../review/native-bay-rollover/README.md) |
| Black Dragon | Creator Idle only | [Source](black-dragon/provenance.json) |
| European Dragon | Creator Idle Stand, Idle Sit, Walk, Run and Fly | [Source](european-dragon/provenance.json) |

The game exposes only the available native motion. Missing horse Gallop/Jump clips remain unfinished. The full existing breed roster keeps its separate authored assets; this integration does not equate four foundations with eighty completed breeds. Source files, bind matrices, skin influences and creator clips remain preserved. [Rebuild status](REBUILD_STATUS.md) records motion and appearance limits and the earlier failed import experiments.

WildMesh 3D’s realistic horse and 3DHaupt’s Black Dragon are **CC BY-NC 4.0**; the dragon’s NoAI restriction is retained. The European Dragon is **CC BY 4.0**. The [attribution archive](ATTRIBUTION.md) and each source’s provenance preserve creator, source link, license and changes. Only the four named native assets are activated by this integration; historical source and validation records for other imports do not establish current gameplay availability.

No new model was downloaded for this publication. Earlier imported roster conversion attempts remain in Git history and the diagnostic reviews. Their old catalogs and shared procedural conversion are not active runtime dependencies for these native models.
